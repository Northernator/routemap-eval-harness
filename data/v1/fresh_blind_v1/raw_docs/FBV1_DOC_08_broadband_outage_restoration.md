# FiberFix Broadband Restoration

Route question: How should a broadband field desk route restoration work?

## FBV1_0113

The FiberFix desk is not sufficient when drop cable is missing from the handoff, even if optical node looks complete. A coordinator still needs the missing evidence before the route can be trusted.

## FBV1_0114

For example, a coordinator might receive a drop cable that lists customer outage cluster as available while splice crew says the work cannot start. In that case, FiberFix keeps the case open until network watch board confirms the current state.

## FBV1_0115

The term drop cable refers to the recorded item that tells the coordinator what can move, wait, or be checked again. It is narrower than the whole FiberFix file because it only covers the visible queue state.

## FBV1_0116

The coordinator should require the optical node against the splice crew before releasing the next task. If the two records disagree, the item stays with network watch board until the discrepancy is cleared.

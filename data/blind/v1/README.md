# RouteMap Blind Benchmark v1 (frozen)

A held-out suite the route engines were **never tuned against**. Generated by `src/blind/generate_blind_v1.py`
(seed 20260623), with ground truth from independent pure-Python code, and locked by SHA-256 in `manifest.json`.

- `arithmetic_blind_500.jsonl` — 500 arithmetic claims (correct / residue-inconsistent / off-by-M), GT by Python exact.
- `schema_outputs_blind_200.jsonl` — 200 JSON outputs vs declared schemas (valid / violation), GT by construction.
- `extraction_blind_100.csv` — 100 passages with gold entities, GT by construction.
- `retrieval_blind_100.jsonl` + `retrieval_corpus.jsonl` — 100 known-answer queries over a 200-doc corpus.
- `manifest.json` — counts + SHA-256 of every file. `BLIND_RESULTS.md` / `.json` — the single scored run.

**Rule:** never edit these files or tune against them. `score_blind_v1.py` refuses to run if a hash changes.
